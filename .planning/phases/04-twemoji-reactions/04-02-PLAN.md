6. Comprehensive unit test suite covering DraftJS contenteditable manipulation, caret placement, and clipboard fallback under DOM simulation.

Create features/reactions/composer-prefiller.ts implementing the 4-step insertion pipeline:
1. Function prefillReplyComposer(anchorElement: HTMLElement, emoji: string, onFallback?: (emoji: string) => void): Promise&lt;boolean&gt;.
2. Target detection (D-05): find the tweet article using anchorElement.closest('article[data-testid="tweet"]') or anchorElement.closest('article'). Within the article, locate the native reply button using selector '[data-testid="reply"]' or 'button[aria-label*="Reply" i]'. If found, call (replyButton as HTMLElement).click() to trigger X's native reply composer flow (modal dialog on feeds, inline focus on status permalinks).
3. Composer polling: implement helper waitForComposer(timeoutMs: number): Promise&lt;HTMLElement | null&gt;. Check every requestAnimationFrame (or 20ms timer) up to COMPOSER_WAIT_TIMEOUT_MS (1000ms) for candidate elements matching replyComposer selector chains: '[role="dialog"] [data-testid="tweetTextarea_0"]', '[role="dialog"] [role="textbox"][contenteditable="true"]', '[data-testid="tweetTextarea_0"]', '[role="textbox"][contenteditable="true"]'.
4. Caret collapse to end (D-07): when composer element is found, call composer.focus(). Obtain window.getSelection(), create range using document.createRange(), call range.selectNodeContents(composer), call range.collapse(false) to position cursor at the very end of any existing draft text, clear existing selection ranges, and add the collapsed range.
5. Rich text insertion (D-06): define textToInsert as emoji + ' ' (with trailing space). Call document.execCommand('insertText', false, textToInsert).
6. Synthetic fallback: check if execCommand returned false or composer element textContent does not contain the emoji. If so, dispatch synthetic InputEvent('beforeinput', { bubbles: true, cancelable: true, inputType: 'insertText', data: textToInsert }) followed by new Event('input', { bubbles: true }).
7. Anti-Abuse Safety Boundary (REACT-04): ensure the code NEVER clicks, focuses, or invokes '[data-testid="tweetButton"]', '[data-testid="tweetButtonInline"]', or any GraphQL create tweet endpoint. Hand complete control to the user to send the reply.
8. If waitForComposer times out or article reply button is not present, call fallback routine (copy to clipboard and invoke onFallback callback per D-08).

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-05 | Denial of Service | waitForComposer polling loop | medium | mitigate | Bounded polling with strict 1000ms timeout (COMPOSER_WAIT_TIMEOUT_MS) using requestAnimationFrame; never hangs indefinitely. |
| T-04-06 | Elevation of Privilege | Programmatic reply posting (Anti-Abuse) | high | mitigate | Strict prefill-only architecture (REACT-04). The extension only inserts text into the composer; zero click events dispatched to submit buttons, zero API posting calls. |
| T-04-07 | Tampering | Caret collapse and existing draft preservation | medium | mitigate | Collapses selection to end (collapse(false)) before inserting text with trailing space (D-07); preserves existing draft contents without overwriting. |
| T-04-08 | Information Disclosure | Clipboard fallback write | low | mitigate | Only the single selected emoji character is written to clipboard upon failure (D-08); zero private tweet or user data copied. |

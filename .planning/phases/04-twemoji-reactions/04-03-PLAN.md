- pointerover / mouseover ({ capture: true }):
  - Check if event target is within '[data-testid="like"]' or '[data-testid="unlike"]'.

  - If event target is within open palette, clear exitGraceTimer.
- pointerout / mouseout ({ capture: true }):
  - If leaving activeLikeButton, clear pending hoverTimer.
  - If palette is open and pointer leaves either activeLikeButton or the palette pill, start exitGraceTimer for EXIT_GRACE_BUFFER_MS (300ms per D-01). When timer expires, closePalette().

  - Clear pending holdTimer.
  - If holdTriggered is true: event.preventDefault(), event.stopImmediatePropagation() to suppress the native Like click. Reset holdTriggered = false.
- click ({ capture: true }):
  - If click target is on Like button: if holdTriggered was true, preventDefault() and stopImmediatePropagation().
  - If normal single click (<500ms): closePalette() immediately and allow native Like action to proceed normally (D-04).

# Phase 04 — UI Design Contract: Twemoji Reactions

> Visual and interaction contract for Phase 4: Twemoji Reactions. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Covers:** REACT-01, REACT-02, REACT-03, REACT-04, REACT-05, REACT-06.

**Scope of this contract:**
1. **Floating Reaction Palette Overlay (`ReactionPalette.tsx`) anchored to Tweet Like Button** (`features/reactions/`):
   - Singleton overlay host mounted inside `#bt-reactions-root` with open Shadow DOM attached at `document.body`.
   - Rounded pill container with theme-synced background (`color-mix(in srgb, var(--bt-surface) 88%, transparent)`), border (`var(--bt-border)`), and backdrop blur (`backdrop-blur-md`).
   - 6 reaction slots with 1.4× hover scale spring bounce (`cubic-bezier(0.34, 1.56, 0.64, 1)`).
   - High-contrast sentiment tooltips above hovered emoji ("Like", "Love", "Haha", "Wow", "Sad", "Fire").
   - 3 visual presentation styles: Normal (system font), Twemoji (classic Twitter SVGs), Animated Noto (Google animated WebPs).
   - Quick customize trigger button ("+") opening the popup Reactions settings panel.
   - Context-aware positioning anchored above the tweet's Like button (`top: rect.top - 56px`, horizontal center alignment with viewport edge protection).
   - Immediate dismiss triggers on window/feed scroll, outside pointerdown, Escape key, or virtualizer node detachment.
2. **Discreet Fallback Notification Toast (`Toast.tsx`)** (`features/reactions/`):
   - Injected inside the shadow root container when DraftJS reply composer fails to mount or replies are restricted (D-08).
   - "Replies unavailable — emoji copied to clipboard" with 3-second auto-dismiss.
   - High-contrast pill toast positioned fixed at viewport bottom-center (`bottom: 24px`, `left: 50%`).
3. **Extension Popup Reactions Panel (`entrypoints/popup/ReactionsPanel.tsx`)**:
   - Registered under `reactions` category in popup registry (`id: 'reactions'`, `caption: 'Reactions'`, `icon: Smile`, `dedicatedPanel: true`).
   - Visual style selector cards: Normal (System), Twemoji (Classic), Animated Noto (Google Animated WebP) with active radio borders.
   - 6-slot customization grid: slot index, emoji preview, sentiment label, slot swap/replace action, and slot reorder controls (Move Left/Right or Move Up/Down).
   - "Reset Default Slots" button with destructive confirmation dialog.
4. **Emoji Catalog Browser Modal / Popover (`EmojiCatalogModal.tsx`)**:
   - Full-width search input with instant debounced filtering across 800+ Google Noto emojis.
   - Horizontal category filter chips: "All", "Smileys", "Gestures", "Animals", "Food", "Activities", "Travel", "Objects", "Symbols".
   - 40×40px clickable emoji cell grid with hover preview and codepoint metadata.
   - Hybrid caching: selected custom emojis cached locally in `chrome.storage.local` (`local:customEmojiCache`) without requiring `host_permissions`.

**Quality bar:** *"Toggling it feels native, not bolted on."* All injected elements inherit theme tokens seamlessly, use native X typography metrics, and operate completely offline without external network requests for default sets.

## Layout & Interaction Contract

### 1. Floating Reaction Palette Overlay (`ReactionPalette.tsx`)

```
               ┌───────────┐
               │   Love    │  <-- Sentiment Tooltip Badge (11px/600, pill)
               └─────▼─────┘
┌───────────────────────────────────────────────────────────┐
│  ( 👍 )   ( ❤️ )*  ( 😂 )   ( 😮 )   ( 😢 )   ( 🔥 )  │ [+] │
└───────────────────────────────────────────────────────────┘
     1        2        3        4        5        6        7
```

- **Mount Target:** Singleton `#bt-reactions-root` fixed overlay container at viewport top-left (`pointer-events: none`). Palette pill container uses `pointer-events: auto`.
- **Primary Visual Anchor:** The hovered emoji slot (slot 2 in diagram) which scales up to 1.4× with spring overshoot (`cubic-bezier(0.34, 1.56, 0.64, 1)`) and displays a high-contrast floating sentiment badge. When idle, the centered Love slot (`❤️`) serves as the visual focal point.
- **Trigger Mechanics:**
  - **Hover Trigger (D-01):** Delegated `pointerover` on Like button (`[data-testid="like"]` or `[data-testid="unlike"]`). 350ms delay timer. Cancels if pointer exits before 350ms.
  - **Hold Trigger (D-02):** Delegated `pointerdown` on Like button. 500ms hold timer. When reached, suppresses the native click event via `e.preventDefault()` and `e.stopImmediatePropagation()`.
  - **Exit Grace Buffer (D-01):** 300ms timer when pointer moves between Like button and floating palette pill.
  - **Normal Click (D-04):** A single click (<500ms) on Like button executes X's native like action and immediately closes any open reaction palette.
- **Dismissal Triggers (D-03):** Immediate dismissal on window/feed scroll, pointerdown outside the palette pill, Escape key, or when the tweet article is detached by X's virtualizer.
- **Anchor Positioning Math:**
  - `paletteLeft = clamp(8, buttonRect.left + (buttonRect.width / 2) - (paletteWidth / 2), viewportWidth - paletteWidth - 8)`
  - `paletteTop = buttonRect.top - 56` (rendered 8px above Like button). If `buttonRect.top < 64`, flips below button: `buttonRect.bottom + 8`.
- **Palette Entrance/Exit (D-18):**
  - Entrance: Snappy 150ms spring slide-up and scale-in (`transform: scale(0.85) translateY(6px)` → `scale(1) translateY(0)` with `opacity: 0` → `1`).
  - Exit: 100ms fade-out (`opacity: 0`).
- **Emoji Rendering Styles (D-11):**
  - **Normal:** `<span className="text-[24px] select-none leading-none">{emoji}</span>`
  - **Twemoji:** `<img src={browser.runtime.getURL('twemoji/' + twemojiCodepoint + '.svg')} alt={emoji} className="w-7 h-7 select-none pointer-events-none" />`
  - **Animated Noto:** `<img src={browser.runtime.getURL('noto-animated/' + notoCodepoint + '.webp')} alt={emoji} className="w-7 h-7 select-none pointer-events-none" />`
- **Accessibility Fallbacks:**
  - Emoji slots: `role="button" aria-label="React with [Label] ([Emoji])"`
  - Customize trigger button `[+]`: `aria-label="Customize reaction palette"`
  - Tooltip: `role="tooltip" aria-hidden="true"`

### 2. Discreet Fallback Notification Toast (`Toast.tsx`)

```

└──────────────────────────────────────────────────────────────┘

- **Accessibility Fallbacks:**
  - Container: `role="status" aria-live="polite"`
  - Close button: `aria-label="Dismiss notification"`

│ ├──────────────────────────────────┤ │
│ │ 4. 😮 Wow        [←] [→] [Change]│ │  48px Slot Row 4

```

- **Primary Visual Anchor:** The active Visual Style Selector Card with high-contrast accent border ring (`border: 2px solid var(--bt-accent)`) and checkmark badge.
- **Style Selector Interaction:** Clicking any style card immediately commits `reactionsSettings.style` to `wxt/storage` and updates all running palette instances live via `storage.onChanged`.
- **Slot Reorder Interaction:**
  - Clicking `[←]` (Move slot left/up): Swaps position with the preceding slot in `reactionsSettings.slots`. Disabled on Slot 1.
  - Clicking `[→]` (Move slot right/down): Swaps position with the following slot in `reactionsSettings.slots`. Disabled on Slot 6.
- **Slot Change Interaction:**
  - Clicking `[Change]` opens the `EmojiCatalogModal` popover targeted to that specific slot index.
- **Destructive Action Confirmation ("Reset to Defaults"):**
  - Clicking "Reset to Defaults" opens an inline confirmation banner:
    - Text: "Reset all 6 reaction slots to default emojis?"
    - Buttons: "Reset Default Slots" (destructive red fill) and "Keep Custom Slots" (neutral surface).
- **Accessibility Fallbacks:**
  - Back navigation button `[←]`: `aria-label="Back to all settings"`
  - Move Left button `[←]`: `aria-label="Move [Label] slot left"`
  - Move Right button `[→]`: `aria-label="Move [Label] slot right"`
  - Change button: `aria-label="Change emoji for [Label] slot"`
  - Reset button: `aria-label="Reset reaction palette to default slots"`

### 4. Google Noto Emoji Catalog Browser Modal (`EmojiCatalogModal.tsx`)

```
┌──────────────────────────────────────┐
│ Choose Reaction Emoji          [✕]   │  Modal Header (20px/600)
├──────────────────────────────────────┤
│ ┌──────────────────────────────────┐ │
│ │ 🔍 Search 800+ emojis...     [✕] │ │  Search Input (40px, rounded-full)
│ └──────────────────────────────────┘ │
│                                      │
│ [ All ] [ Smileys ] [ Gestures ] ... │  Scrollable Category Filter Chips
├──────────────────────────────────────┤
│ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐  │
│ │👍 │ │👎 │ │👏 │ │🙌 │ │👐 │ │🤝 │  │  40×40px Clickable Emoji Grid
│ └───┘ └───┘ └───┘ └───┘ └───┘ └───┘  │  (881 categorized emojis)
│ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐  │
│ │✌️ │ │🤞 │ │🤟 │ │🤘 │ │👌 │ │🤌 │  │
│ └───┘ └───┘ └───┘ └───┘ └───┘ └───┘  │
├──────────────────────────────────────┤
│ Selected: 👍 Thumbs Up (U+1F44D)     │  Footer metadata (11px/600)
└──────────────────────────────────────┘
```

- **Trigger:** Clicking `[Change]` on any of the 6 slot customization rows in `ReactionsPanel`.
- **Primary Visual Anchor:** Full-width search input with magnifying glass icon and instant debounced filter.
- **Search & Filter Mechanics:**
  - Real-time instant filtering with 150ms debounce across emoji labels and keywords from Google Fonts `api.json`.
  - Category chip filter selects specific emoji group ("Smileys", "Gestures", "Animals", "Food", etc.).
  - Selecting an emoji immediately replaces the target slot's emoji and codepoints, fetches and caches SVG/WebP assets into `local:customEmojiCache`, saves settings, and smoothly closes the modal.
- **Empty State (Zero Search Results):**
  - Displays centered icon, heading "No Emojis Found", and body copy: "No emojis match '[query]' in [Category]. Try a different keyword, check spelling, or select 'All Categories'."
- **Error State (Catalog Fetch Failure):**
  - Displays alert icon, heading "Emoji Catalog Unavailable", and body: "Unable to load the remote Google Noto emoji catalog. Check your internet connection or click 'Retry Catalog Fetch'."
- **Accessibility Fallbacks:**
  - Close button `[✕]`: `aria-label="Close emoji browser"`
  - Search input: `aria-label="Search emojis by keyword"`
  - Emoji grid cell: `role="button" aria-label="Select [Emoji Name] emoji"`

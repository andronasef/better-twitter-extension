<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Bundled Static Assets → Extension Runtime | Offline SVG and WebP assets loaded directly from extension bundle |
| Extension Storage → Memory | Deserialized JSON settings and custom emoji cache entries from chrome.storage.local |
| DOM Selectors → Target Elements | Querying dynamic X web application DOM without trusting class names |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering | public/twemoji/*.svg assets | medium | mitigate | SVGs are static vector files bundled at build time; zero script elements or event handlers inside SVG files. |
| T-04-02 | Information Disclosure | web_accessible_resources declaration | medium | mitigate | All web-accessible resources are scoped strictly to *://x.com/* and *://twitter.com/* with zero wildcard origins (*://*/* or &lt;all_urls&gt;), preventing arbitrary websites from fingerprinting extension installation (audit-build Assertion 2). |
| T-04-03 | Denial of Service | chrome.storage.local cache growth | medium | mitigate | Reactions settings and cache schema are typed and bounded; customEmojiCache is limited to user-picked slots and uses lightweight data URIs without unlimited storage permission. |
| T-04-04 | Elevation of Privilege | Third-party CDN hotlinking | high | mitigate | Zero CDN hotlinking (REACT-06, D-13). All default assets are bundled in the extension package; remote fetching for customization is CORS-verified and never uses eval. |
</threat_model>

Implement features/reactions/catalog.ts and its unit tests:
1. Export NOTO_API_URL = 'https://googlefonts.github.io/noto-emoji-animation/data/api.json'.
2. Implement fetchEmojiCatalog(): Promise&lt;CatalogEmoji[]&gt;.
- Fetches NOTO_API_URL with CORS mode.
- Parses response into normalized CatalogEmoji array containing codepoint, emoji character, name, category, and keywords array.
- In-memory cache ensures catalog is only fetched once per popup session.
- Gracefully handles network failure by throwing descriptive error.
3. Implement searchEmojiCatalog(catalog: CatalogEmoji[], query: string, categoryFilter?: string | null): CatalogEmoji[].
- If categoryFilter is provided and not 'All', filter items matching category.
- If trimmed query is empty, return category-filtered items.
- Split query into lowercase tokens by whitespace.
- Match items where EVERY token matches at least one of: name, keywords, category, or codepoint.
- Return filtered list preserving category order.
4. Implement cacheCustomEmoji(slotId: string, codepoint: string): Promise&lt;CustomEmojiCacheEntry&gt;.
- Fetches Twemoji SVG from jsDelivr (https://cdn.jsdelivr.net/gh/jdecked/twemoji@latest/assets/svg/{codepoint}.svg).
- Converts SVG to data URI: data:image/svg+xml;utf8,...
- Fetches Google Noto Animated WebP from Google Fonts (https://fonts.gstatic.com/s/e/notoemoji/latest/{codepoint}/512.webp).
- Converts WebP ArrayBuffer to base64 Data URI: data:image/webp;base64,...
- Updates customEmojiCacheItem in chrome.storage.local with { twemojiSvg, notoWebp, updatedAt: Date.now() }.
5. Create tests/unit/reactions-catalog.test.ts testing searchEmojiCatalog with single-token, multi-token, and category chip filtering; test empty query fallback; test data URI formatting.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Remote GitHub Pages API → Extension Fetch Client | Consuming remote api.json from Google Fonts repository |
| User Search Input → Catalog Filter Engine | Unsanitized user string input filtered in memory |
| Extension Storage → Quota Budget | Storing base64/SVG data URIs in chrome.storage.local |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-13 | Elevation of Privilege | Remote catalog fetching | high | mitigate | Endpoint returns standard CORS headers; zero host_permissions requested in manifest.json, preserving audit-build.mjs Assertion 1. |
| T-04-14 | Denial of Service | chrome.storage.local quota overflow | medium | mitigate | Only user-selected slots are cached as Data URIs (max 6 slots × ~150KB = ~900KB total); quota indicator and "Clear Cached Emojis" action prevent storage exhaustion. |
| T-04-15 | Tampering | Malicious SVG injection from remote assets | medium | mitigate | Remote SVG assets fetched from verified jsDelivr twemoji repository; rendered via standard img src data URIs without inline innerHTML injection. |
| T-04-16 | Information Disclosure | Search query leakage | low | mitigate | Search filtering runs 100% locally in browser memory over pre-fetched catalog; zero network requests dispatched per keystroke. |
</threat_model>

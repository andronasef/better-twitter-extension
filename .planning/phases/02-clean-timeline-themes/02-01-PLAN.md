<objective>
Build the Timeline & Sidebar Declutter Engine implementing CLEAN-02 ("What's Happening" / trends removal), CLEAN-03 ("Who to Follow" removal), and CLEAN-05 (vanity metrics count stripping, detail stats removal, profile counts sub-toggle, and tooltip sanitization).

Deliverables:
1. Pure CSS declutter rules on `html[data-bt-clean-sidebar]`, `html[data-bt-hide-metrics]`, and `html[data-bt-hide-profile-counts]` ensuring zero DOM thrashing and 60fps scrolling.
2. Tooltip sanitizer observing transient `[role="tooltip"]` to sanitize count text (e.g. "24 Likes" -> "Like").
3. Expanded settings schema (v2 migration) and popup Timeline panel featuring primary toggles and indented sub-toggles with visual connector lines.
</objective>

# Phase 02 — UI Design Contract: Clean Timeline & Themes

> Visual and interaction contract for Phase 2: Clean Timeline & Themes. Generated by gsd-ui-researcher.

**Covers:** CLEAN-02, CLEAN-03, CLEAN-04, CLEAN-05, THEME-01, THEME-02, THEME-03, THEME-04, THEME-05, THEME-06, THEME-07.

**Scope of this contract:**
1. **Extension Popup UI** (`entrypoints/popup/`):
   - Expansion of the **"Timeline"** category panel with declutter toggles and sub-toggles: "Clean right sidebar" (bundle), "Hide vanity metrics" (with action icons kept, analytics hidden, detail stats hidden), "Hide profile follower counts" (sub-toggle), "Following first on Home" (tab reorder), and "Hide For You tab completely" (sub-toggle).
   - New **"Themes"** category tile in the grid and dedicated **Themes Panel** featuring visual thumbnail preview cards for all 6 presets (Default, Dracula, Nord, Matrix, Minimal, Old Twitter) plus a **Custom Accent** hex color picker with instant live application.
2. **Injected On-Page UI & Styles** (`entrypoints/x.content/`):
   - Zero-FOUC master theme stylesheet (`<style id="bt-theme">`) and CSS custom property token definitions (`--bt-theme-*`) for Dracula, Nord, Hacker/Matrix, and universal custom accent overrides.
   - **Minimal Theme** layout transforms: centered timeline column, hidden right sidebar, and slim 68px collapsed navigation rail.
   - **Old Twitter 2015** layout transforms: 3-column desktop layout, horizontal classic top navbar (46px), discrete bordered tweet cards (`#ffffff` on `#e6ecf0`), rounded-square avatars (`border-radius: 4px`), and left-column mini profile dashboard card.
   - **Vanity Metrics & Tooltip Sanitizer**: non-destructive count stripping on tweet action buttons, detail stats block suppression, and native tooltip count sanitization.

**Quality bar:** *"Toggling it feels native, not bolted on."* All toggles update live via `chrome.storage.local` with zero page reload and zero layout shift.

### 6. Tab Reordering & Following Auto-Selection Contract

- **Visual Order (CSS Flex)**:
  - Tab 1 ("For You"): `order: 2 !important;`
  - Tab 2 ("Following"): `order: 1 !important;`
  - Tab 3+ (Pinned Lists): `order: 3 !important;`
  - When `hideForYouTab` is ON: `tabList > :nth-child(1) { display: none !important; }`
- **Auto-Selection Behavior**:
  - When route watcher detects transition to `/home`:
    - Checks if Following tab has `aria-selected="true"`.
    - If not selected, dispatches `.click()` once.
    - Sets route-scoped boolean `hasAutoSelected = true`.
    - If user manually clicks "For You" during that page view, no override occurs. Flag resets only when navigating away from `/home` and returning.

### 7. Vanity Metrics & Tooltip Sanitization Contract

1. **Tweet Action Counts Stripping**:
   - `[data-testid="app-text-transition-container"]` and numeric `span:has(span)` inside action buttons are hidden (`display: none !important`).
   - Action SVGs (Reply, Repost, Like, Bookmark, Share) remain 100% visible and interactive with normal hover rings.
   - Analytics / View count button (`a[href*="/analytics"]`, `[data-testid="analytics"]`) is hidden completely.
2. **Tweet Detail Stats Block**:
   - On status permalink pages (`/status/123`), the expanded stats container (`article div:has(> a[href$="/retweets"])`) is hidden.
   - Timestamp and date link remain visible.
3. **Profile Page Counts**:
   - When `hideProfileCounts` is ON, follower/following count numbers on profile headers (`a[href$="/followers"]`, `a[href$="/following"]`) are hidden.
4. **Native Tooltip Sanitizer**:
   - Intercepts floating `[role="tooltip"]` text mutations.
   - Sanitizes dynamic count strings:
     - `/^[0-9,.]+[KM]?\s+Likes$/i` → `"Like"`
     - `/^[0-9,.]+[KM]?\s+Reposts$/i` → `"Repost"`
     - `/^[0-9,.]+[KM]?\s+Replies$/i` → `"Reply"`
     - `/^[0-9,.]+[KM]?\s+Bookmarks$/i` → `"Bookmark"`
     - `/^[0-9,.]+[KM]?\s+Views$/i` → `""` (tooltip suppressed)

1. Update `lib/theme-engine.ts`:
   - Export `injectThemeStylesheet(): void`:
     - Checks if `<style id="bt-theme">` already exists in document.
     - Creates `<style id="bt-theme">`, assigns `textContent = generateThemeCss()`.
     - Appends immediately to `document.documentElement || document.head || document.body`.
   - Export `applyThemeAttributes(theme: ThemeId, customAccent: string | null): void`:
     - Sets `data-bt-theme="<theme>"` on `document.documentElement`.
     - If `customAccent` is provided:
       - Sets `document.documentElement.style.setProperty('--bt-theme-accent', customAccent)`.
     - Else:
       - Removes `--bt-theme-accent` property from `document.documentElement.style` so theme preset default takes effect.

2. Update `entrypoints/x.content/index.ts`:
   - In `defineContentScript`:
     - Synchronously call `injectThemeStylesheet()` at top of `main()` (at `runAt: 'document_start'`).
     - Synchronously read cached theme from `chrome.storage.local.get('local:settings')` or `settingsItem.getValue()`.
     - Immediately invoke `applyThemeAttributes(settings.theme, settings.customAccent)`.
     - Inside `settingsItem.watch()`:
       - Update `applyThemeAttributes(newSettings.theme, newSettings.customAccent)`.
       - Update other `data-bt-*` attributes (`cleanSidebar`, `swapHomeTabs`, etc.) live.

1. Implement `features/tab-reorder/index.ts`:
   - State variables:
     - `let hasAutoSelectedForRoute = false;`
     - `let routeUnsubscribe: (() => void) | null = null;`
     - `let tabObserver: MutationObserver | null = null;`
   - Export `autoSelectFollowingTab(root?: ParentNode): boolean`:
     - Checks if current `window.location.pathname` is `/home` or `/` (or home route).
     - Resolves `followingTab` via `withFeature('swapHomeTabs').resolve('followingTab', root)`.
     - If `followingTab` exists:
       - If `followingTab.getAttribute('aria-selected') === 'true'`, returns `true` (already selected).
       - If `!hasAutoSelectedForRoute`:
         - Sets `hasAutoSelectedForRoute = true`.
         - Dispatches `followingTab.click()` (or `(followingTab as HTMLElement).click()`).
         - Returns `true`.
     - Returns `false` if tab was not found.
   - Export `resetAutoSelectGuard()`:
     - Resets `hasAutoSelectedForRoute = false`.
   - Export `tabReorder` feature controller:
     - `id: 'swapHomeTabs'`
     - `init()`:
       - Sets `data-bt-swap-tabs="true"` on `document.documentElement`.
       - Wires `onRouteChange(() => { resetAutoSelectGuard(); checkAndAutoSelect(); })`.
       - If on `/home`, attempts `autoSelectFollowingTab()`. If not found immediately, sets a brief observer on `primaryColumn` to catch the tablist mounting.
     - `teardown()`:
       - Removes `data-bt-swap-tabs` attribute from `document.documentElement`.
       - Disconnects observer and unhooks route change listener.
       - Resets guard.
   - Export `hideForYou` feature controller:
     - `id: 'hideForYouTab'`
     - `init()`: sets `data-bt-hide-for-you="true"` on `document.documentElement`.
     - `teardown()`: removes `data-bt-hide-for-you` from `document.documentElement`.

   - Register `tabReorder` and `hideForYou` in `createSettingsDispatcher`.

     - Given `resetAutoSelectGuard()` is called: click is dispatched again on next call.
     - Given Following already has `aria-selected="true"`: click is NOT dispatched.

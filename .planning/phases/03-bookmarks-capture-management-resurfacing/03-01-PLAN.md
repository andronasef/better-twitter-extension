<objective>
Build the Core Storage, Schema & Extraction Engine for Better Twitter bookmarks (Phase 3 Tracer Slice).

Deliverables:
1. Normalized TypeScript data models (`BookmarkItem`, `BookmarkFolder`, `BookmarkSyncState`, `BookmarksSettings`) ensuring low memory footprint (~500B average per bookmark, max 1KB, zero raw blobs per D-15).
2. WXT storage items (`local:bookmarks`, `local:folders`, `local:bookmarkSync`, `local:bookmarksSettings`) with v4 migration and default non-deletable "Uncategorized" folder (D-06).
3. Storage quota supervisor implementing 80% warning detection and 95% bounded auto-pruning that removes oldest Uncategorized items while strictly safeguarding custom user folders and tagged bookmarks (D-16, BOOK-10).
4. High-fidelity normalization engine (`features/bookmarks/extractor.ts`) parsing X's live GraphQL bookmark responses (handling `Tweet`, `TweetWithVisibilityResults`, note tweets, pagination cursors) and fallback DOM scraping (`article[data-testid="tweet"]`) (BOOK-01, BOOK-02).
5. Fast, dependency-free multi-token client-side search engine (`features/bookmarks/search.ts`) filtering bookmarks by text, author, and tags in <3ms (BOOK-05).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| X GraphQL API response → Extractor | Unsanitized network responses from X containing arbitrary tweet content, handles, and URLs |
| X DOM article element → DOM Scraper | Arbitrary DOM nodes injected by X or third-party page scripts |
| Extension Storage → Memory | Deserialized JSON items loaded into browser memory |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | extractor.ts reading raw GraphQL responses | medium | mitigate | All fields are strictly parsed with defensive type checks (optional chaining, fallback defaults) without using eval or dynamic execution. |
| T-03-02 | Denial of Service | chrome.storage.local quota exhaustion | high | mitigate | Strict payload normalization (~500B average, no raw image blobs per D-15), 80% warning banner, and 95% automated eviction of oldest Uncategorized bookmarks (D-16, BOOK-10). |
| T-03-03 | Information Disclosure | Bookmark metadata leakage | high | mitigate | Storage uses strictly local MV3 chrome.storage.local. Zero remote servers, zero outbound telemetry, zero third-party analytics per project constraints. |
| T-03-04 | Elevation of Privilege | Dependency supply chain in search indexer | high | mitigate | Zero external dependencies (no FlexSearch, no Lunr, no search workers). Built-in multi-token substring scanner complies 100% with audit-build.mjs Assertion 5. |
</threat_model>

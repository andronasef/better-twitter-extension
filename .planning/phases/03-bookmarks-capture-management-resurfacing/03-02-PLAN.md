<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MAIN World bridge.ts → ISOLATED World bridge-client.ts | CustomEvent dispatch across DOM boundary passing intercepted JSON payloads |
| X Action Bar button → Delegated event listener | User clicks on native X action buttons triggering extension state transitions |
| Popover Mount → document.body | Injected Shadow DOM portal rendering React UI over native page |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-05 | Elevation of Privilege | bridge.ts DOM event detail passing | high | mitigate | CustomEvent details contain only plain serialized JSON data objects; no executable function references or code strings are passed across the boundary. |
| T-03-06 | Denial of Service | Rapid repeated clicks on bookmark button | medium | mitigate | Click handler debounces assignment popover mounts and performs atomic writes to local storage. |
| T-03-07 | Repudiation | Desynchronization between X cloud and local storage | medium | mitigate | Dual-save passes event to native X reconciler while simultaneously capturing locally; unbookmarking synchronizes deletion (D-09). |
| T-03-08 | Tampering | React virtualizer conflict on action row | high | mitigate | Zero DOM child injection into role="group"; popover is rendered in a separate portal attached to document.body anchored via getBoundingClientRect() (D-05). |
</threat_model>

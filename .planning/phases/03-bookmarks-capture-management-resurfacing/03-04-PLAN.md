1. Implement candidate selection in features/bookmarks/resurfacing.ts:
   - Function selectResurfacingCandidate(bookmarks: BookmarkItem[], folders: BookmarkFolder[]): BookmarkItem | null:
     - Builds Set of eligible folder IDs from folders where folder.resurfaceEnabled !== false.
     - Filters bookmarks to include only candidates where:
       - neverResurface is not true.
       - snoozedUntil is undefined or snoozedUntil <= Date.now().
       - At least one ID in item.folderIds is in the eligible folder IDs set.
     - If filtered candidate pool is empty, returns null.
     - Sorts candidates with multi-factor ranking:
       - Primary: item.resurfaceCount ascending (least frequently resurfaced first).
       - Secondary (tie-breaker): (item.lastResurfacedAt ?? 0) ascending (longest time since last resurfaced).
       - Tertiary (tie-breaker): item.savedAt ascending (oldest saved bookmark first).
     - Returns top-ranked candidate.

2. Implement timeline injection controller in features/bookmarks/resurfacing.ts:
   - Function initResurfacing():
     - Feed scope check (D-14): verifies window.location.pathname === '/home' or window.location.pathname === '/'; if not, exits immediately. Excluded from /bookmarks, profile pages, search, and status details.
     - Reads bookmarksSettingsItem: checks resurfacingEnabled and resurfacingInterval (default 20, range 5-50 per D-12). If resurfacingEnabled is false, exits.
     - Subscribes to shared tweet pipeline using onTweetSeen:
       - Maintains tweetCounter since last resurfacing insertion.
       - When tweetCounter >= resurfacingInterval:
         - Selects candidate using selectResurfacingCandidate. If null, resets counter and continues.
         - Targets the most recently observed tweet cell.
         - Virtualizer protection (BOOK-09): creates container div with attribute data-bt-resurfaced-cell="true", style: contain: content; min-height: 120px; overflow-anchor: auto;.
         - Inserts container immediately after the tweet cell. If insertion point is in view, waits for scroll threshold to avoid displacement.
         - Mounts ResurfacedCard React island inside container (Task 2).
         - Updates candidate: candidate.resurfaceCount++, candidate.lastResurfacedAt = Date.now(). Commits update to bookmarksItem.
         - Resets tweetCounter = 0.
   - Function teardownResurfacing():
     - Removes injected data-bt-resurfaced-cell elements and unsubscribes pipeline listener.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

# Phase 03 — UI Design Contract: Bookmarks (Capture, Management & Resurfacing)

> Visual and interaction contract for Phase 3: Bookmarks (Capture, Management & Resurfacing). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Covers:** BOOK-01, BOOK-02, BOOK-03, BOOK-04, BOOK-05, BOOK-06, BOOK-07, BOOK-08, BOOK-09, BOOK-10.

**Scope of this contract:**
1. **In-Page Bookmarks Hub UI on `x.com/bookmarks` & `x.com/i/bookmarks`** (`features/bookmarks/in-page-ui/`):
   - Sticky top toolbar mounted directly beneath X's native header inside `div[data-testid="primaryColumn"]`.
   - Full-width instant search input with clear button (debounced at 150ms).
   - Horizontal scrollable filter chips: "All Bookmarks", custom folder chips with color dot and bookmark count, tag chips (`#tag`), and "+ New Folder" trigger button.
   - Inline folder/tag management popover (`BtPopover`) for creating, editing, coloring, and deleting folders.
   - Active filter indicators with "Clear Filters" CTA.
   - In-place feed filtering with native-feel empty state cards (for zero search matches and initial un-synced state).
2. **Action Row Integration & Tweet Save Popover** (`features/bookmarks/action-bar.ts`):
   - Delegated capture-phase click listener on X's native Bookmark button (`button[data-testid="bookmark"]`).
   - Dual-save execution: triggers X's native cloud save while simultaneously opening Better Twitter's folder selector popover (`BtPopover`).
   - Clean folder assignment popover anchored virtually to the bookmark button: folder search/filter, multi-select checkboxes, quick "+ Create Folder" inline input, and dismiss action.
   - Native action bar visual indicator: bookmark icon fills, and hover tooltip displays assigned folder names.
   - Quick-save setting bypass (`askFolderOnSave: false`) auto-assigning directly to "Uncategorized" without showing popup.
   - Synchronized unbookmarking removing local copy when unsaved on X.
3. **Timeline Resurfacing Cards on `/home`** (`features/bookmarks/resurfacing.ts`, `ResurfacedCard.tsx`):
   - Native-styled tweet card injected into the Home timeline (`/home` Following and For You) every N tweets (default 20, slider 5–50).
   - Header banner: "📌 Resurfaced from [Folder Name]" with folder color badge and quick-action menu button.
   - Card container with subtle theme accent border tint (`var(--bt-theme-accent)`).
   - Quick-action dropdown menu (`BtDropdownMenu`): "Snooze for 7 days", "Don't resurface this tweet", "Move to folder...", "Remove from bookmarks".
   - Virtualizer resilience: below-viewport insertion, explicit height containment (`contain: content`), and DOM re-anchoring to eliminate scroll jumps.
4. **Extension Popup Bookmarks Panel** (`entrypoints/popup/BookmarksPanel.tsx`):
   - New "Bookmarks" category tile in the popup grid with `Bookmark` icon.
   - Sync status & trigger card: "Sync Bookmarks Now" primary CTA, live progress counter, last sync timestamp, and error status alerts.
   - Timeline Resurfacing controls: master toggle, cadence slider (5 to 50 tweets), and folder eligibility checklist.
   - Quick-save toggle: "Ask for folder when bookmarking".
   - Storage quota usage bar: progress bar showing bytes used against 10MB quota, 80% warning banner, and auto-pruning audit info.
   - Data management buttons: "Export Bookmarks (JSON)" and "Import Bookmarks (JSON)".

**Quality bar:** *"Toggling it feels native, not bolted on."* All injected elements inherit theme tokens seamlessly, use native X typography metrics, and operate completely offline without external network requests.

## Layout & Interaction Contract

### 1. In-Page Bookmarks Hub (`x.com/bookmarks`)

```
┌──────────────────────────────────────────────────────────────┐
│ [←] Bookmarks                                          (···) │  <-- Native X Header
├──────────────────────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ 🔍  Search bookmarks by text or author...            [✕] │ │  <-- Full-width Search Input
│ └──────────────────────────────────────────────────────────┘ │      (40px, rounded-full)
│                                                              │
│ [ All Bookmarks (142) ]  [ ● Dev Tools (24) ]  [ ● AI (18) ] │  <-- Filter Chips Row
│ [ #typescript (9) ]      [ + New Folder ]                    │      (32px pills, scrollable)
├──────────────────────────────────────────────────────────────┤
│ Active filter: "Dev Tools"                       Clear Filters│  <-- Filter Bar (when active)
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  [ Tweet Card 1 ]                                            │
│  [ Tweet Card 2 ]                                            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

- **Mount Target:** Appended immediately beneath X's sticky header within `div[data-testid="primaryColumn"]`.
- **Primary Visual Anchor:** Full-width search pill input (40px) with icon and subtle border drawing focus immediately.
- **Accessibility Fallbacks:** All icon-only actions declare explicit `aria-label`s:
  - Clear search input button `[✕]`: `aria-label="Clear search input"`
  - Popover close trigger: `aria-label="Close dialog"`
  - Folder chip color dots: declared as `aria-hidden="true"` with color name announced via chip text.
- **Search Interaction:** Typing filters the bookmarks list in real time with a 150ms debounce. Pressing `Escape` or clicking `[✕]` clears the search input.
- **Folder / Tag Chips:**
  - Horizontal scrollable row with hidden scrollbars.
  - Active chip has accent border and highlight: `background-color: var(--bt-surface); border: 1.5px solid var(--bt-accent)`.
  - Inactive chips use `--bt-surface` background with subtle border.
  - Clicking "+ New Folder" opens `BtPopover` directly below the chip.
- **Folder Management Popover (`BtPopover`):**
  - Name input field (Body typography, 15px/400).
  - 6 color swatches (Blue, Green, Yellow, Pink, Purple, Orange).
  - Primary button: "Create Folder".
  - If editing existing folder: includes "Rename Folder" and red "Delete Folder" CTA.

### 2. Action Row Tweet Save Popover

```
┌──────────────────────────────────────────────────────┐
│ article[data-testid="tweet"]                         │
│ Tweet text content...                                │
│                                                      │
│ [💬 12]   [🔄 4]   [❤️ 89]   [🔖]             [📤] │
└─────────────────────────────────┬────────────────────┘
                                  │ (virtual anchor)
               ┌──────────────────▼───────────────┐
               │ Save to Folders                  │
               ├──────────────────────────────────┤
               │ 🔍 Filter folders...             │
               ├──────────────────────────────────┤
               │ [✓] 📁 Uncategorized             │
               │ [ ] 📁 Dev Tools                 │
               │ [ ] 📁 AI & Research             │
               │ [ ] 📁 Design Inspiration        │
               ├──────────────────────────────────┤
               │ [ + Create Folder ]              │
               └──────────────────────────────────┘
```

- **Primary Visual Anchor:** The active checked folder row (e.g. `[✓] Uncategorized`) with accent checkmark.
- **Accessibility Fallbacks:**
  - Search filter input inside popover: `aria-label="Filter folders"`
  - Inline "+ Create Folder" action: `aria-label="Create new folder"`
- **Trigger:** User clicks native `button[data-testid="bookmark"]`.
- **Dual Action:** The click event propagates to X to execute cloud bookmarking, while the capture handler opens `BtPopover` anchored to the button rect.
- **Selection:** Checkbox toggles folder membership. Changing checks immediately commits `folderIds` to `local:bookmarks`.
- **Inline Folder Creation:** Clicking "+ Create Folder" transforms the footer row into an inline input with "Create Folder" button.
- **Dismissal:** Clicking outside, pressing Escape, or navigating away smoothly closes the popover.
- **Quick-Save Mode:** When "Ask for folder when bookmarking" setting is OFF, clicking bookmark saves directly to "Uncategorized" with no popover, and the tooltip displays "Saved to Uncategorized".

### 3. Resurfaced Timeline Card (`/home`)

```
┌──────────────────────────────────────────────────────────────┐
│ 📌 Resurfaced from Dev Tools                            (···)│ <-- Header Banner (32px)
├──────────────────────────────────────────────────────────────┤
│ [Avatar]  Author Name @author · May 14, 2025                 │
│                                                              │
│ Resurfaced tweet body content text...                        │
│                                                              │
│ [💬 34]   [🔄 12]   [❤️ 140]   [🔖 Assigned: Dev Tools]      │
└──────────────────────────────────────────────────────────────┘
```

- **Primary Visual Anchor:** Top header banner ("📌 Resurfaced from [Folder Name]") with accent pin icon and 3px left accent stripe immediately distinguishing the card from native feed tweets.
- **Accessibility Fallbacks:**
  - Overflow action menu trigger `(···)`: `aria-label="Resurfaced bookmark options"`
  - Pin icon: `aria-hidden="true"`
- **Visual Differentiation:**
  - Header: `13px/600` Label text with accent `📌` pin icon and folder name.
  - Border: Left accent stripe (`border-left: 3px solid var(--bt-accent)`) or subtle card border tint.
  - Overflow Menu (`BtDropdownMenu`):
    - "Snooze for 7 days": hides tweet from resurfacing until timestamp `Date.now() + 7 * 86400000`.
    - "Don't resurface this tweet": sets `neverResurface: true`.
    - "Move to folder...": opens folder assignment sub-popover.
- **Virtualizer Protection:**
  - Inserted below the visible viewport so scrolling is never displaced.
  - Card container sets `contain: content` and explicit dimension bounds.
  - Cell tracker observer monitors virtualizer unmounts and cleanly restores card when scrolled into view.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Search Input → Search Engine | Arbitrary text typed into search pill input |
| X Feed Container → Filter Engine | Target DOM nodes of X's native virtualized tweet list |
| Hub UI Mount → primaryColumn | DOM injection point under native header |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-09 | Tampering | Feed filtering via DOM manipulation | high | mitigate | Uses declarative attribute hiding (data-bt-bookmark-filtered) rather than removing or reparenting X's React DOM nodes, preventing React reconciliation crashes. |
| T-03-10 | Denial of Service | Rapid keystroke search thrashing | medium | mitigate | 150ms debounce on input change and microsecond-fast multi-token array scan (<3ms) prevent UI stutter. |
| T-03-11 | Information Disclosure | In-page folder names visible in DOM | low | accept | Folder names reside only in local client storage and extension-owned Shadow DOM attributes, never broadcast over network. |
| T-03-12 | Repudiation | Accidental deletion of bookmarks during folder delete | high | mitigate | Destructive confirmation dialog and automatic re-filing of all bookmarks to 'Uncategorized' ensures zero tweet data loss (D-03). |
</threat_model>

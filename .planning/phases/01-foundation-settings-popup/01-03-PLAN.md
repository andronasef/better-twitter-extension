<objective>
Make the foundation honest about its own failures and fast enough to be invisible: a selector layer that reports which feature stopped matching, a two-tier surfacing path that reaches the user without the console, and a pipeline measured under real scroll load.

Purpose: Phase 1's fifth success criterion is that when X changes its markup the user gets a reported miss for the one affected feature rather than a feature that silently stops working. X ships unannounced markup and cohort changes — this is not a hypothetical. The same plan closes the performance and cleanup half of the foundation, because a pipeline that reports its failures but stutters the feed is not shippable either.

Output: Per-feature miss reporting surfaced on the action badge and persisted across service-worker teardown, plus a measured 60fps scroll with no observer accumulation.
</objective>

Implement D-11's three-condition heuristic exactly, and no more than that — one counter per (featureId, selectorName) pair, not a statistics engine. A selector counts as missing only when its owning feature is enabled, the pipeline has emitted at least one tweet-seen event on this page, and the chain has returned zero matches across three consecutive pipeline ticks.

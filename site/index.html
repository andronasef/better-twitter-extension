Core Engine

Zero-FOUC Promoted Ad Stripper

X serves promoted tweets dynamically within its React virtual scroller. Better Twitter listens via a centralized MutationObserver and removes sponsored cells before paint. Promoted accounts in search and timelines are purged with zero layout shifts.

Target Selectors: div[data-testid="cellInnerDiv"] matching promoted badge markers and sponsored user entities. Zero network request delays.

Real-world result

No "Promoted" badges in search results. No sponsored crypto accounts pinned to your timeline. No full-page takeover ads when refreshing feeds.

Feed Architecture

Chronological Following by Default

X's web client defaults every session to the algorithmic "For You" feed. Better Twitter swaps tab ordering using CSS flex rules (order: -1) and auto-activates the Following feed on navigation without dispatching erratic synthetic click events.

Implementation: CSS flex ordering on div[role="tablist"] + single-activation route listener with duplicate guard.

No feed hijacking

Every time you open x.com/home, you land on the accounts you actually chose to follow, in reverse chronological order.

Custom CSS Engine

Community Themes & Hex Accent Picker

Built-in support for Dracula, Nord, Hacker Matrix, and Lights Out AMOLED. Stylesheets are injected synchronously at document_start to eliminate flash of unthemed content. Pick custom hex colors to replace X's default blue throughout the UI.

Zero FOUC injection

Overrides X's hardcoded CSS variables directly. Timeline, composer, modals, and navigation sidebars all match your chosen palette consistently.

Composer Integration

Twemoji Reaction Palette

Hover or hold the Like button to select from 6 bundled Twemoji reactions. When selected, Better Twitter opens X's native reply modal and prefills the editor with your emoji. The extension never posts or likes tweets for you — the send action always remains in your hands.

DraftJS Target: Synthetic beforeinput and caret positioning ensure emoji registers in X's internal React editor state without breaking drafts.

Safe by design

Zero automation risk. No shadow likes, no automatic retweets, no background API tokens. Every interaction requires your explicit confirmation.

Local Storage Hub

Bookmark Folders & Timeline Resurfacing

File saved tweets into color-coded folders directly inside x.com/bookmarks. Search bookmark text or author handles instantly from local indexed storage. Optionally weave saved bookmarks back into your home feed every N tweets so good threads don't rot forgotten.

Storage Budget: Structured quota manager with automatic pruning and JSON export/import backup.

100% Offline & Private

Your bookmarks never touch an external server or telemetry pipeline. Stored entirely in your browser's private extension storage.
